Homepage

Hello and Welcome to this website! This website's purpose is to document Lego Star Wars Sets that have been released, as well as a variety of information about them. This is not a site for selling these sets. If you find that a set is missing, there is a form you can fill out on the Submit a Set page to let us know what we missed. You will be able to see some examples of how the sets are presented in the database on this page. If you click on them you will be able to see more information about them.
